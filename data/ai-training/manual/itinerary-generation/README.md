# Manual Itinerary Generation Examples

Each `.json` file in this directory is a single sanitized example for the `itinerary_generation` dataset project.

Required fields:
- `id`
- `taskType`
- `language`
- `input`
- `output`
- `labels`
- `provenance`

Keep provider facts as `groundingIds` or short factual references. Do not copy raw provider descriptions unless the license explicitly permits training use.
