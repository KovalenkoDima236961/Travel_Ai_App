# Analyze AI Online Regression

1. Compare candidate and baseline metrics in the same rollout window.
2. Include candidate failures, skipped shadows, timeouts, and missing
   comparisons.
3. Segment by language, destination coverage, task type, and rollout mode.
4. Inspect safe error codes and normalized validation issue counts.
5. Decide whether to keep shadowing, pause, reject, or retrain from approved
   curated data.
